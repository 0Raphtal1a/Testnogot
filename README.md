# Маникюр — примерка с Pinterest

Веб-приложение для iPhone: фото руки → дизайны с досок Pinterest → ИИ рисует их на ногтях → свайпы «нравится / нет» → вкладка «Избранное».

## Что понадобится

1. **Ключ ИИ для картинок** — сейчас настроено на moduleapi.pro с моделью `gpt-image-2.5` (одна примерка ≈ 2,5 млн токенов пакета, 30–60 сек). Подойдёт любой OpenAI-совместимый API с `/images/edits`, либо OpenRouter.
2. **Аккаунт Vercel** — vercel.com (бесплатный план).
3. **Node.js** на компьютере — nodejs.org (LTS).

## Деплой (Windows)

```powershell
cd путь\к\nails-app
npx vercel login
npx vercel            # на все вопросы — Enter
npx vercel env add IMAGE_API_KEY        # ключ moduleapi.pro, выбери Production
npx vercel env add ACCESS_CODE          # любой пароль, чтобы чужие не тратили твой баланс
npx vercel --prod
```

В конце будет ссылка вида `https://nails-xxx.vercel.app`.

## На iPhone

1. Открой ссылку в **Safari**.
2. Поделиться → **На экран «Домой»** (так избранное не сотрётся и приложение откроется во весь экран).
3. Введи код доступа при первом запуске.

## Настройки (переменные окружения Vercel)

| Переменная | Зачем |
|---|---|
| `IMAGE_API_KEY` | ключ OpenAI-совместимого Images API (основной режим) |
| `IMAGE_API_BASE` | адрес API, по умолчанию `https://moduleapi.pro/v1` |
| `IMAGE_MODEL` | модель, по умолчанию `gpt-image-2.5` (можно `gpt-image-2`) |
| `ACCESS_CODE` | пароль на приложение (рекомендую) |
| `OPENROUTER_API_KEY` / `OPENROUTER_MODEL` | запасной режим через OpenRouter + Gemini, если `IMAGE_API_KEY` не задан |

Ключ **никогда не кладётся в репозиторий** — только в Vercel или в файл `.env` на сервере (образец — `.env.example`).

## Как устроено

- `public/` — интерфейс (HTML/CSS/JS без сборки).
- `api/pins.js` — пины с доски / профиля / поиска Pinterest (публичный виджет-API → RSS → HTML, по очереди).
- `api/tryon.js` — отправляет фото руки и дизайн в `/images/edits`, возвращает фото с маникюром.
- Фото руки, готовые примерки и избранное хранятся в IndexedDB на iPhone. Готовые примерки кешируются — повторно не оплачиваются.
- Генерируются только верхняя и следующая карточки, чтобы не тратить деньги на то, что не досмотрела.

## Если что-то не работает

- **«Pinterest не ответил»** — Pinterest иногда блокирует серверы. Добавь ссылку на конкретную доску (она работает надёжнее поиска).
- **«Закончились деньги»** — пополни пакет у провайдера API.
- **«API не умеет редактировать фото»** — провайдер не поддерживает `/images/edits`, нужен другой.
- **Карточка с ошибкой** — нажми «Повторить»; некоторые картинки ИИ не берёт (коллажи, текст).
